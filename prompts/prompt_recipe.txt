Extract recipe data and generate enrichment fields as JSON.

EXTRACT (from text):
- title (REQUIRED, string)
- cuisine (string or null)
- prep_time, cook_time, total_time (string or null)
- servings (number or null)
- difficulty ("easy"|"medium"|"hard" - infer if needed)
- ingredients (REQUIRED, array of {quantity, unit, item})
- instructions (REQUIRED, array of strings)

GENERATE (always include):
- nutrition_estimate: {calories: number, protein/carbs/fat: string}
- substitutions: 3 strings like "Replace X with Y for Z"
- shopping_list: {category: [items]} (2+ categories)
- related_recipes: 3 recipe names

JSON RULES: 
- Escape quotes and backslashes: \" and \\
- Use lowercase true/false/null only
- No trailing commas
- All strings in double quotes
- Return ONLY valid JSON - no markdown, no explanations, no text outside the JSON object

MINIMAL WORKING EXAMPLE (compact single line):
{"title":"Toast","cuisine":null,"prep_time":"5m","cook_time":"3m","total_time":"8m","servings":1,"difficulty":"easy","ingredients":[{"quantity":"2","unit":"slices","item":"bread"},{"quantity":null,"unit":null,"item":"butter"}],"instructions":["Toast bread","Spread butter"],"nutrition_estimate":{"calories":150,"protein":"3g","carbs":"20g","fat":"6g"},"substitutions":["Replace butter with oil","Use whole wheat bread","Add jam"],"shopping_list":{"bakery":["bread"],"dairy":["butter"]},"related_recipes":["Scrambled Eggs","Pancakes","Oatmeal"]}
